# Flávio e os Parças

Painel cívico com fontes sobre o que fizeram no poder os líderes com quem Flávio Bolsonaro diz querer se alinhar (Bukele, Jair Bolsonaro, PiS, Kast, Milei, Orbán e Trump), com o governo Lula (2023 a 2025) como comparação.

**Site:** https://destrava-conversas.github.io/eoflavio/
**E a Economia?:** https://destrava-conversas.github.io/eoflavio/economia/

## Princípios

- Toda ação listada tem fonte.
- Linguagem neutra, sem previsões e sem vínculo partidário.

## Estrutura

- `index.html`: o painel inteiro (HTML, CSS e dados em um único arquivo).
- `og-e-o-flavio.png`: imagem de pré-visualização para redes sociais.
- `economia/index.html`: a página E a Economia?, com dados oficiais governo por governo.
